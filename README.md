# Ahmed Video Uploader

TikTok Login Kit + Content Posting API demo.

The GitHub Pages site is only a landing page. The Flask app must run on Render because GitHub Pages cannot execute Python.

Expected Render URL:
https://ahmed-video-uploader.onrender.com

TikTok Redirect URI:
https://ahmed-video-uploader.onrender.com/callback/

Set these Render environment variables:
- FLASK_SECRET_KEY
- TIKTOK_CLIENT_KEY
- TIKTOK_CLIENT_SECRET
- TIKTOK_REDIRECT_URI
